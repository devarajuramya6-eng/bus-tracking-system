# Environment Variables

The following environment variables are used by the application:

*   `DATABASE_URL`: The database connection string (e.g., `<SET_IN_DEPLOYMENT_ENVIRONMENT>`).
*   `SECRET_KEY`: The application's secret key for sessions and tokens (e.g., `<SET_IN_DEPLOYMENT_ENVIRONMENT>`).
*   `REDIS_URL`: The Redis connection string (e.g., `<SET_IN_DEPLOYMENT_ENVIRONMENT>`).
